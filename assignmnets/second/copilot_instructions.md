# Copilot Instructions

## General Guidelines
- Always follow Python best practices for code style, structure, and documentation.
- Think step by step before answering. Ensure answers are correct, relevant, and avoid hallucinations or unsupported claims.
- If designing APIs, strictly adhere to RESTful principles, proper naming conventions, and required specifications.
- For frontend or Chrome extension tasks, follow standard web development and Chrome extension guidelines (manifest structure, permissions, event handling, etc.).
- Provide concise, actionable, and context-aware solutions.
- Never include harmful, hateful, or inappropriate content.
- Use modern libraries and frameworks when appropriate.
- Validate code for errors and test where possible.

## Python-Specific Rules
- Use PEP8 for formatting and naming.
- Prefer built-in modules and standard libraries unless otherwise specified.
- Add docstrings and comments for clarity.
- Handle exceptions gracefully.
- Write modular, reusable code.
- Include requirements.txt for dependencies.

## API Design Rules
- Use clear, descriptive endpoint names.
- Follow RESTful conventions (GET, POST, PUT, DELETE).
- Validate input and handle errors with proper status codes.
- Document endpoints and expected request/response formats.

## Frontend & Chrome Extension Rules
- Use semantic HTML, CSS, and modern JavaScript (ES6+).
- For Chrome extensions, follow manifest.json standards and permissions.
- Ensure UI is user-friendly and accessible.
- Handle browser events and background scripts as per Chrome extension documentation.

## Step-by-Step Thinking
- Break down complex tasks into smaller steps.
- Plan before coding, and review solutions for correctness.
- Avoid assumptions; gather context before answering.
